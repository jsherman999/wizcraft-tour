# Wizcraft — the starter tour

The narrated tour video for **wizcraft**, a strategy game played on a real Minecraft
world from your web browser. This repository exists only to host the video, so that
the link plays in a browser instead of offering a download.

**Watch it:** <https://jsherman999.github.io/wizcraft-tour/>

Direct file: [`wizcraft-starter.mp4`](wizcraft-starter.mp4) — 1920×1080, H.264, 8.6 MB,
3 minutes 42 seconds.
